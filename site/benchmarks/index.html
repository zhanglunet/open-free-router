THREE EVIDENCE LAYERS

三层证据，不互相冒充。

01 · 本站真实请求

可用性与延迟

Cloudflare 服务器每 15 分钟轮换探测登记模型。它回答“维护者服务器现在能否完成一次最小请求”，不代表你的账号、地区或网络。

02 · 注册表声明

功能密度与任务适配

上下文、最大输出、推理和工具调用来自注册表声明；免费状态必须有来源和有效期。功能多不等于答案质量高。

03 · 第三方独立评测

智力、编码与 Agent 指数

可通过 Artificial Analysis 官方 API 导入；展示时保留 Index 版本、更新时间、来源链接和模型匹配置信度。

怎么理解这个分数？

它是“当前接入准备度”，不是模型智力排行榜。当前公开目录以提供商级服务端状态和延迟为主：同一提供商下的模型可能继承同一轮快照，不能把差异很小的分数理解为逐模型质量差异。逐模型真实质量应结合下方独立基准和你的目标任务测试。
