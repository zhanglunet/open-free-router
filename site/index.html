registry.yaml

唯一模型真源

保存提供商、模型能力、上游 ID 和刷新策略。真实 API Key 只留在本机，不进入 Git。

proxy.py

单端口反向代理

支持 bare、prefix、upstream、provider/upstream 和 Codex 安全别名五种模型 ID。

responses.py

Codex 协议桥

转换 Responses API、SSE 与函数工具历史，并保留 Gemini thought signature。

serve.py

一条命令启动

同时运行代理、控制台、定时刷新器与模型目录同步，无需外部 Web 框架。

WHY IT EXISTS

它不是新的模型平台，
而是你的本地适配层。

01

给 Codex 配置第三方模型

生成独立 profile 和模型目录，不覆盖正常的 OpenAI 配置。

02

减少多客户端重复配置

Pi、OMP、OpenCode、Hermes 共享一个代理地址与统一 registry。

03

追踪免费模型变化

按计划轮询支持的提供商，刷新模型、上下文窗口和工具能力。

04

把凭据留在自己的机器

客户端只拿本地代理 token，上游 API Key 不写入同步后的客户端配置。

QUICK START · 快速开始

从安装到第一次路由，
只需要四步。

01INSTALL

安装到独立虚拟环境

git clone https://github.com/zhanglunet/open-free-router.git cd open-free-router python3 -m venv .venv .venv/bin/pip install -e .
02SETUP

录入你自己的提供商 Key

.venv/bin/open-free-router setup

Key 写入本机 registry；该文件默认被 Git 忽略。

03SERVE

启动代理、控制台与刷新器

.venv/bin/open-free-router serve

Proxy：127.0.0.1:8337 · UI：127.0.0.1:9057

04CONNECT

同步并启动 Codex

.venv/bin/open-free-router sync --agent codex \ --codex-model 'or/gpt-oss-20b:free' codex --profile open-free-router

  prefix: or
  upstream_url: https://openrouter.ai/api/v1
  api_key: ${YOUR_LOCAL_KEY}

保存上游连接、私有 Key、模型 ID 和能力元数据。不要提交该文件。

命令作用什么时候用

setup交互式录入 API Key首次安装或增加提供商
refresh拉取免费模型变化立即更新 registry

SECURITY BOUNDARY

知道什么留在本地，
比“免费”更重要。

LOCAL / PRIVATE

不会同步给客户端

  • 上游提供商 API Key
  • registry.yaml 与备份
  • 代理和控制台 token
  • 本机客户端配置路径
UPSTREAM / REQUIRED

推理时必须发送

  • 选择的上游模型 ID
  • 当前请求的提示与上下文
  • 工具定义和必要工具结果
  • 提供商要求的鉴权信息
OPERATION RULES

建议的安全习惯

  • 默认只监听 127.0.0.1
  • 定期轮换上游 Key
  • 不要提交 config/registry
  • 公开前执行全历史 secret scan
注意

本地代理降低的是配置泄漏和多客户端复制风险，不会改变上游提供商对请求内容的处理方式。敏感任务仍需阅读并遵守对应提供商的数据政策。

TROUBLESHOOTING

常见问题，直接定位。

端口 8337 显示 Address already in use+

已有代理进程正在运行。先用 lsof -nP -iTCP:8337 -sTCP:LISTEN 确认 PID；不要重复启动第二个 serve。

Codex 的 /model 看不到第三方模型+

重新运行 sync --agent codex，完全退出旧 Codex 会话，再使用 codex --profile open-free-router 启动。

模型能聊天，但不能使用 shell 工具+

该模型可能尚未标记或验证 tool_calling。显式选择已验证模型，或在 registry 中确认其能力后重新同步。

上游返回 401、403 或计费错误+

代理路由已经成功，但提供商 Key、免费额度或账户状态不可用。打开本地 UI 检查对应 provider，而不是修改 Codex profile。
