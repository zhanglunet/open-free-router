02 · DELIVERY
A

故障恢复与隔离

  • 429 不再因错误文案永久禁用 credential。
  • 403 按模型隔离，多个模型拒绝后才归因 credential。
  • terminal 状态增加有界恢复探测，声明式 reset header 对所有 429 生效。
B

数据新鲜度与模型目录

  • 公开 catalog 改用模型级、带时效的实测证据。
  • 过期、缺失、未来时间戳和降级数据不再冒充实时事实。
  • refresh --probe-new 以真实 1-token 请求决定是否采用新模型。
C

客户端与站点工程化

  • Kimi Code 支持新版配置路径和实测可用模型筛选。
  • sync.exclude 在裸 sync/serve 自动同步路径生效。
  • 完成全站审计、CI、内容 hash 资源指纹和 v0.4.0 发布。
