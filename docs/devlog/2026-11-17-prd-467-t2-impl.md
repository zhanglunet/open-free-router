## 首测抓出的实现错误（修正入档）

1. windows 字典形状错误（defaultdict 嵌套 vs 扁平 count_key 键）；
2. observed_header 过期判在写入时而非读时——advance 之后过期应生效；
3. 守门口径：派发前置检查是「recorded + in_flight < limit」（不含本次 demand）——首版误加 demand 导致 limit=N 时第 N 个请求被拦；
4. 计数丢失守门仅在「该窗口上限已知」时生效（上限未知+已用未知=仍只计数）；
5. 租约必须携带 per-window demand 并在释放后排除（in_flight 只算未释放）；
6. 文档红线：源码不得出现「到 reset_at 清零」的实现（§2.6 写死，测试 NotIn 钉值——docstring 字面也算，措辞改写）。
