# PRD-466/T2 开发记录：签名目录拉取与验证（2026-11-17）

> trend issue #2251。承接 T1 设计（#2250，docs/plans/2026-11-17-signed-catalog-design.md，已合 #191）。

## 交付

- `src/open_free_router/ed25519_verify.py`：纯 Python RFC 8032 Ed25519（验签为主+测试用 keygen/sign）——仓库零加密依赖纪律下自实现（RFC 官方向量 keygen/sign 逐字节对齐+PyNaCl 交叉验证）。两处首次自测抓出的错：hwcd-3 a=-1 加法公式符号、压缩漏除 z——修正后 keygen/sign 与 RFC 8032 TEST 1 完全一致。
- `src/open_free_router/catalog_sync.py`：verify_catalog_bytes（先验签后解析的顺序写死：验签失败连解析都不做，整份丢弃+大声报错）+ is_catalog（§2.1 结构校验：形状不对整份丢弃不修补）+ 版本底线三态（skipped_older/up_to_date/apply，MIN_CATALOG_VERSION 随基线）+ fetch_and_verify（OFR_CATALOG_BASE_URL/PUBKEY/SYNC_DISABLED 三环境变量；fetch_fn 注入默认 requests 20s 超时；https 强制）+ run_sync（状态文件 data/catalog-state.json 原子落盘：applied_version/applied_tier/applied_json/last_sync_ms/last_error，degraded/failed 都大声记录）+ retry_backoff_seconds（退避不低于 5 分钟、上限 30 分钟）。
- `tests/test_prd466_t2_catalog_sync.py`：20 例全绿（RFC 向量/先验后解析顺序/篡改拒绝/缺签名拒绝/错钥拒绝/形状校验/版本底线三态含不可回滚钉值/降级不断线/总开关/状态文件原子+last_error/退避下限）。

## 基线偏差如实声明

- 全仓既有 11 个失败均为 sandbox 系列测试（test_sandbox_runner/hardening/acceptance），main 基线同败（本机子进程环境限制所致），与本链无关、零修改。
