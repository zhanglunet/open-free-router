- `src/open_free_router/fusion.py`：FusionRouter——dispatch()（同一 prompt 并行分发 N 个模型，dispatch_fn 注入式不发真实网络；单路失败 error 隔离在 result 内不传播；超时有上限）+ synthesize()（评审模型从多路草稿合成答案，附来源标注；评审失败降级返回最优单路 degraded=true 不空手而归；全部失败返回 None 也标 degraded）+ 成本护栏（fusion_enabled 默认 false；budget_per_request 上限；max_targets 硬上限 3 不可绕过；超预算/超上限明确拒绝）。
- `tests/test_prd475_t2_fusion.py`：13 例全绿（并行分发/单路失败隔离/默认关闭/预算超限/硬上限不可绕过/评审合成来源标注/评审失败降级不空手/全部失败 None/AST 零网络/词表/零 intelligenceRank）。
