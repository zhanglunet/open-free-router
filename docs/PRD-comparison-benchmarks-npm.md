# 工具比较、模型评测与 npm 分发 PRD

状态：P0 已实现，npm v0.3.0 已公开发布
日期：2026-08-02

## 1. 目标

1. 用来源可追溯的矩阵解释模力自由港与 OmniRoute、9Router、LiteLLM、Free Router 的定位差异。
2. 在“当前能否调用”之外，引入模型质量证据，但不混淆本地实测、声明能力与第三方基准。
3. 提供符合 Node 用户习惯的 npm 安装入口，同时保持 Python CLI 为唯一实现和事实源。

## 2. P0 范围与验收

### 2.1 工具比较页

- 维度覆盖定位、规模、免费证据、协议、路由、韧性、发现、MCP、评测、分析、实时状态、数据边界和安装形态。
- 数字必须带快照日期和官方来源；未知写“资料未说明”，不得写成“没有”。
- 手机端表格可横向滚动，提供按用户目标选择工具的建议。

### 2.2 模型评测页

- 自由港任务适配分 v1 = 服务端可用性 35% + 免费证据 25% + 声明功能密度 30% + 最近延迟 10%。
- 精确计分：可用性为可用 35、未验证 12、不可用 0；免费证据为已核验 25、待补 10、过期 5、无记录 5、错误 0；功能密度分乘 30%；延迟为不高于 1s / 1.5s / 3s / 5s / 更慢 / 未测分别 10 / 9 / 6 / 3 / 1 / 2。
- 分数只描述当前接入就绪度，不称为智力分或质量分。
- 服务器公开目录当前使用提供商级可用性与延迟快照，同一提供商模型可能继承同一轮结果；不能冒充逐模型质量实测。
- 外部列展示 Intelligence、Coding、Agentic 和匹配说明；整组快照没有导入显示“未导入”，已导入快照中的单条字段缺失显示“该记录缺失”，都不补零。
- 图片只用于提出产品方向，不能作为逐点抄录的数据源。

### 2.3 Artificial Analysis 导入

- Key 仅从 `ARTIFICIAL_ANALYSIS_API_KEY` 读取；支持官方 API 分页和 `--input` 离线快照。
- 输出字段白名单：模型名、slug、厂商、三项指数、任务成本、价格、中位吞吐/首字延迟、注册表匹配、版本、时间与署名。
- 模型匹配采用规范化精确匹配或保守模型族匹配；未匹配保持独立，不强行挂接。
- 先完整请求和校验，再原子替换公开 JSON；失败不破坏现有快照。

### 2.4 npm 包

- 包名候选 `open-free-router`；`open-free-router` 与 `ofr` 两个 bin 指向同一启动器。
- Node 18+；运行时要求 Python 3.11+；首次运行创建隔离缓存环境。
- `prepack` 从仓库复制 Python 源码、元数据与默认无密钥注册表，凭据样式校验失败即拒绝打包。
- v0.3.0 已在所有者明确授权后发布；发布前完成 tarball 清单、凭据扫描和真实安装烟测。
- 官网提供独立 `/guide/npm/` 页面，覆盖环境检查、首次引导、缓存边界、Codex 接入、升级卸载和常见错误。

## 3. 非目标

- 不复刻 Artificial Analysis 的完整图表、原始数据集或专有方法。
- 不把第三方分数用于自动替用户选择模型或改变路由，除非未来单独设计可解释、默认关闭的策略。
- 不在 npm 启动器维护路由逻辑、注册表或客户端适配器的 JavaScript 副本。

## 4. 后续 P1

- 提供商扩容按公开免费证据、协议兼容、凭据隔离、真实文本请求和错误语义五道门槛逐家准入；候选不计入已支持规模。
- 第一批直接 API 候选：Cerebras、SiliconFlow、Together AI、Fireworks AI、SambaNova、DeepInfra；第二批评估 Cloudflare Workers AI、Hugging Face Inference、Pollinations、Puter。
- 本地模型（Ollama、LM Studio、vLLM）与 OAuth 账号连接单列能力域，不把本地运行或网页会话包装成“云端免费提供商”。
- 获得并配置 Cloudflare 专用评测 API Secret，按供应方限额定时刷新外部快照。
- 增加模型版本/推理档位人工复核队列，显示 exact / family / unreviewed 匹配置信度。
- 增加用户自定义任务集的本地评测命令，默认不上传 Prompt 或答案。
- 为后续版本增加 Python/npm 版本一致性校验与自动化发布审批流程。

## 5. 风险与边界

- 第三方数据受来源条款约束，网站必须署名；大规模再分发或商业使用前需重新确认授权。
- 模型名称相同不代表推理档位、量化、系统提示和提供商实现相同。
- npm 是公开注册表；私有 GitHub 仓库并不会阻止 tarball 中源码被任何人下载。
