# PRD-131/T1 设计：有序后端列表 + doctor 检查 + 自动换路方案

> trend issue #654 · 已有 PRD-059 failover 审计 + PRD-257 统一路由

## 方案
- 有序后端列表：配置文件声明优先序（primary → fallback_1 → ...）
- doctor 检查：启动时/手动触发——逐一探活后端并输出健康报告
- 自动换路：primary 不健康 → 自动切换到下一个健康后端（换路事件入审计）

## 与 PRD-294 划界
PRD-294 管 @后端 引用解析（选路指令层）；本条管运行时自动换路（配置层）。

## 红线
