# 模力自由港品牌规范

## 品牌架构

- 中文主品牌：**模力自由港**
- 英文副品牌：**FreeModel Port**
- 技术引擎：**Open Free Router**
- 主口号：**全球免费大模型，一站发现、实测、接入。**
- 品牌宣言：**让每一个可用的免费模型，都有一条清晰航路。**

“模力”代表不同厂商和不同能力的大模型；“自由”代表免费可用、自由选择、
配置自主和避免供应商锁定；“港”代表汇聚、验证、调度和出发。

## Logo

Logo 由开放门廊、中心路由节点和三条模型航路组成。外轮廓形成抽象的 `M`，
底部开放空间表示用户始终保有选择权。

| 资产 | 用途 |
|---|---|
| `site/assets/brand/modelport-mark.png` | 512px 主标志 |
| `site/assets/brand/modelport-mark-192.png` | 头像和小尺寸页面标志 |
| `site/assets/brand/favicon.png` | 浏览器图标 |
| `site/assets/brand/og-modelport.jpg` | 1200×630 社交分享卡 |

主标志由内置图像生成工具按 `logo-brand` 规范生成，再通过本地色键去背、裁切和
多尺寸验证。社交分享卡按最终网站的文字、配色和港口雷达构图单独生成，并逐字
核对中文主品牌、口号和英文副品牌。

## 颜色

| 名称 | 色值 | 用途 |
|---|---|---|
| 深港蓝 | `#061120` | 主背景 |
| 航路蓝 | `#496DFF` | 品牌识别、结构层级 |
| 雷达青 | `#24D6C8` | 主行动、扫描信号 |
| 可用绿 | `#4ADE80` | 仅表示真实验证通过 |
| 航图白 | `#EAF5FF` | 主要文字 |

黄色只表示待验证，红色只表示当前不可用。不要用状态色暗示未经测试的模型质量。

## 品牌语言

1. 先说明“免费大模型”，再说明发现、实测与接入能力。
2. 明确区分正式可用模型、不可用模型和目录候选。
3. 不把功能密度包装成模型智力或质量排名。
4. 强调本地控制、凭据隔离和用户选择权。
5. 保留原始项目来源与 MIT License 署名。
